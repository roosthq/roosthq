# Icon asset sources & licenses

Self-hosted (no CDN) so the kiosk never depends on an external asset host.
Fetched from each project's official GitHub repo at build time - see
`web/src/icons/catalog.ts` for the exact concept -> Unicode codepoint mapping
used to pick each file.
